## Programming fundamentals

1. Java fundamentals
2. Class and interface inheritance
3. Generics and type variables
4. Recursive functions and data structures
5. Functional interfaces (e.g. Comparator)

## Software engineering

1. Asymptotic complexity analysis
2. JUnit testing framework
3. Performance testing
4. OOP design patterns

## Lists, Stacks and Queues

1. List ADT interface
2. ArrayList implementation
3. LinkedList implementation
4. Comparative runtime analysis
5. Stack interface and implementations
6. Queue interface and implementations
7. Basic list, stack, and queue applications

## Searching and sorting

1. Linear vs. binary search
2. Quadratic sorts: selection, bubble, insertion
3. Sort properties: stability, adaptivity, in-place (i.e. space complexity)
4. Linearithmic sorts: mergesort and quicksort
5. Hybrid sorts and variants
6. Performance testing and practical design considerations (partially-sorted, duplicates, cache-locality, etc.)
7. Applications of sorting (e.g. closest pair)
